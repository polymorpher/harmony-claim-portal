Recover the private key of a Harmony Ledger address

For an address on the Harmony path m/44'/1023'/0'/0/N, the path Ledger's Harmony apps use, when its ONE or vault shares on Ethereum need a wallet that can sign Ethereum transactions. Everything happens in this file: its security policy blocks every network request, so nothing you type can leave this computer through it.

Before you type your recovery phrase
  • Anyone who learns the phrase controls everything on this Ledger, on every chain. Nobody from Harmony or the migration portal will ever ask for it.
  • Use a computer you trust. Disconnect it from the internet (turn off Wi-Fi, unplug the network cable) and close other programs.
  • A phrase typed into a computer is no longer only on the Ledger. After you move these funds, move everything else on this Ledger to a new recovery phrase.

Addresses of this recovery phrase

Find the address you use with the Ledger; the older Harmony app always uses #0. Show its private key only when you are ready to import it. If none matches, check the words and the passphrase: a different passphrase gives entirely different addresses.

#AddressPrivate key

After you have the key

  1. Import it into an Ethereum wallet on the computer you will use. In MetaMask, open the account menu, choose to add or import an account, pick Private key and paste it. The new account shows the same 0x address as above.
  2. On migrate.country/vault, connect that wallet to withdraw vault shares, and send the ONE to an address you control, for example an account of the Ethereum app on your Ledger.
  3. Close this file. If you copied the key, clear your clipboard; clipboard history and sync may keep it.

The key is derived with BIP-39 and BIP-32, the same standard the Ledger uses. Compare this file's SHA-256 with the one published on migrate.country/ledger before using it.
